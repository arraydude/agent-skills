## Time & Price Alignment

Align entries with optimal session times when multiple timeframes converge.

**Incorrect (ignoring time element):**

```
- Trading at random times without session awareness
- Not understanding timeframe hierarchy
- Missing power hour alignment
```

**Correct (time-aware trading):**

```
Power hour: 17:00 ET — all timeframes align (new daily candle).

Timeframe hierarchy:
- Macro: 1M / 2W / 3D / 2D / 1D
- Daily: 12H / 8H / 6H / 4H / 3H / 144min / 2H / 90min / 1H
- Entry: 15min / 5min

Best session times (ET):
- NY: 08:00 (90min/3H), 09:00 (2H/4H/8H), 11:00 (90min/2H/3H/6H)
- London: 03:00 (2H), 05:00 (90min/2H/3H/4H/6H/12H)
- Asia: 20:00 (90min/3H), 21:00 (2H/4H), 23:00 (90min/2H/3H/6H)
```
